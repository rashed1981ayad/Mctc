# فحص ملفات PDF

كل PDF مرفوع يظل في مجلد خاص مؤقت حتى يجتاز:

1. حد الحجم الحالي (10 MiB) ومطابقة الامتداد والتوقيع.
2. فحص بنية الملف بواسطة qpdf؛ تُرفض الأخطاء والتحذيرات والملفات المشفرة.
3. تحليل أسماء الكائنات المفكوكة بواسطة qpdf؛ تُرفض JavaScript والإجراءات الإضافية والملفات المضمنة والنماذج والمحتوى التفاعلي المحدد في السياسة.
4. فحص ClamAV بتعريفات لا يزيد عمرها عن سبعة أيام وحدود لحجم المحتوى المفكوك وعمق التحليل والوقت.

هذه سياسة رفض وفحص، وليست إعادة كتابة أو تنقية CDR. لا تُعدّل أصول الملفات القديمة. لا يضمن أي ماسح اكتشاف جميع التهديدات.

قد يستغرق الفحص عشرات الثواني. نموذج Nginx يتيح انتظار استجابة الإدارة حتى 240 ثانية؛ اضبط أي وكيل/CDN أمامه بما يناسب ذلك، وإلا قد تنتهي مهلة العميل قبل اكتمال الحفظ.

## الإعداد

ثبّت qpdf وClamAV من مصادرهما الرسمية، وحدّث تعريفات ClamAV بواسطة freshclam قبل بدء استخدام رفع PDF. النسخ المحلية المحمولة المجهزة على Windows هي qpdf 12.4.2 وClamAV 1.5.4 داخل server/.tools (مستبعدة من Git ولا تُنشر تلقائيًا).

يمكن ضبط PDF_QPDF_PATH وPDF_CLAMSCAN_PATH وPDF_CLAMAV_DATABASE في server/.env. عند عدم تحديدها تُستخدم الأدوات المحمولة المحلية إن وجدت، وإلا أدوات PATH وقاعدة ClamAV الافتراضية.

تحديث التعريفات المحلية من جذر المشروع في PowerShell:

```powershell
& './server/.tools/clamav/clamav-1.5.4.win.x64/freshclam.exe' --config-file=server/.tools/clamav/freshclam.conf --quiet
```

ملف freshclam.conf المحلي يتضمن مسار الجهاز الحالي؛ عدّله عند نقل المشروع. في الإنتاج جهّز خدمة freshclam للتحديث اليومي، وشغّل أدوات الفحص بحساب محدود الصلاحيات مع حدود ذاكرة/CPU على مستوى نظام التشغيل أو حاوية. مهلة العملية في التطبيق ليست بديلًا عن عزل النظام. حدّث الأدوات نفسها دوريًا.

## الملفات القديمة وإعادة الفحص

من جذر المشروع:

```sh
npm --prefix server run pdf:scan
```

يفحص الأمر كل PDF في server/uploads ويعرض APPROVED أو BLOCKED دون حذف الأصل. أعد تشغيله دوريًا وبعد تحديث مهم للتعريفات. نتائج الفحص القديمة لا تنتهي تلقائيًا؛ إعادة الفحص الفاشلة تلغي الموافقة السابقة لنفس المحتوى.

مسار التنزيل يتحقق من موافقة مرتبطة ببصمة SHA-256 وسياسة الفحص الحالية؛ أي ملف قديم غير مفحوص أو ملف تغير محتواه يُحجب. مجلد .pdf-verdicts خاص ولا يجوز نشره أو السماح للمستخدمين بالكتابة فيه. لا تضبط Nginx/CDN لتقديم uploads مباشرة متجاوزًا Express. الروابط الخارجية للداتا شيت ليست ملفات مرفوعة ولا يشملها هذا الفحص.

عند غياب الأدوات أو التعريفات أو تعطل الفحص، يُرفض رفع PDF بحالة 503 ولا يُنشر الملف. عند اكتشاف ملف غير مقبول تُعاد 400. يبقى حد الحجم والتنزيل كـ attachment وnosniff وحجب نطاق الإدارة قائمًا. يُسمح بفحص واحد في وقت واحد لكل عملية Node؛ المحاولات المتزامنة تحصل على رسالة لإعادة المحاولة.
